Mode A: Bubbles

Letters float upward in bubbles. Pop them by pressing the matching key before they reach the top!

  • Miss limit: 6 misses max

Mode B: KeyMagnet

Keyboard precision drill. Hit target keys on a responsive virtual keyboard layout as fast as you can.

Features:
  • Selectable Key Sets (Home Row, Numbers, All)
  • Tracks average response time (ms)
  • Visual key highlight & feedback
  • Timed precision challenge
